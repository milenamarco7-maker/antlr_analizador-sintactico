Mi proyecto contiene la definición de una gramática ANTLR4. Para que tu entrada sea aceptada, puede ser:
*Asignación de variables
*Estructura de decisión como por ejemplo switch
*Salida estándar
De lo contrario, tu entrada ingresada será inválida y el programa no se ejecutará

Pasos para ingresar una entrada:
1. Ve al archivo "input.txt"
2. Borra el contenido del archivo
3. Ingresa la entrada que desees
4. Preesiona CONTROL + S para guardar los cambios
5. Abre una terminal e ingresa el comando npm start
De esta manera, deberías recibir el resultado esperado
